# 📁 Estrutura do Projeto — Desafio Front-end

Este projeto foi desenvolvido utilizando **HTML, CSS e JavaScript puro**, com organização simples e direta para facilitar manutenção e evolução.

## 📂 Estrutura de Pastas

A organização dos arquivos segue o padrão abaixo:

```
📦 projeto
 ┣ 📁 assets
 ┃ ┗ 📄 (imagens, ícones, fontes, etc.)
 ┣ 📁 css
 ┃ ┗ 📄 style.css
 ┣ 📁 js
 ┃ ┗ 📄 script.js
 ┣ 📄 index.html
 ┣ 📄 desafio.html
 ┗ 📄 signup.html
```

---

## 📝 Descrição dos Arquivos

### 🔹 index.html  
Página principal do projeto.

### 🔹 desafio.html  
Página referente ao desafio proposto no projeto.

### 🔹 signup.html  
Página de cadastro do usuário.

### 🔹 pasta `assets/`  
Contém imagens, ícones e outros arquivos estáticos.

### 🔹 pasta `css/`  
Contém os arquivos de estilo, como o `style.css`.

### 🔹 pasta `js/`  
Contém os scripts JavaScript responsáveis pela interação do site.

---

## ▶️ Como Executar o Projeto

Basta abrir qualquer um dos arquivos `.html` no navegador, por exemplo:

```
index.html
```

Ou, se preferir, use **Live Server no VS Code** para uma melhor experiência.
